How You'll Be Judged

Judging Criteria

Every submission is evaluated across four equally-weighted dimensions by a senior panel.

01

Problem Definition

Is the problem real, well-scoped, and worth solving? Does the agent address a genuine pain point in capital markets?

02

Design

Is the agent well-architected? Does it handle edge cases, errors, and user experience thoughtfully?

03

Value

What is the measurable impact — time saved, revenue generated, or quality improved? Can it scale?

04

Governance

Is it safe, auditable, and compliant? Does it include human-in-the-loop controls appropriate for a regulated environment?
